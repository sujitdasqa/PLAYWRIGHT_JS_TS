## Chapter Guide

### Chapter 01: Basics

This chapter covers the foundational JavaScript concepts you need before diving into Playwright.

| File | Description |
|------|-------------|
| `javascript-keywords.md` | A quick reference guide for JavaScript reserved keywords |
| `identifier-rules.js` | Comprehensive guide on naming variables, functions, and classes in JS. Includes examples for `camelCase`, `PascalCase`, `snake_case`, and `UPPER_SNAKE_CASE` |
| `vscode-shortcuts.md` | Essential Visual Studio Code keyboard shortcuts for Windows to boost your productivity |
| `verifySetup.js` | Run this file to verify your Node.js environment is set up correctly |
| `practice001-06-05-26.js` | Practice exercise #1 |
| `practice002-6-5-26.js` | Practice exercise #2 |

**Key Concepts Covered:**
- JavaScript keywords and reserved words
- Identifier naming conventions and best practices
- Variables, constants, and data types
- Functions and classes
- VS Code productivity tips

## Prerequisites

Before you begin, ensure you have the following installed:

1. **Node.js** (v18 or higher recommended)
   ```bash
   node --version
   ```

2. **Visual Studio Code**
   - Download from: [https://code.visualstudio.com/](https://code.visualstudio.com/)
   - Recommended extensions:
     - ESLint
     - Prettier
     - Playwright Test for VSCode

3. **Git**
   ```bash
   git --version
   ```

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/sujitdasqa/PLAYWRIGHT_JS_TS.git
   cd PLAYWRIGHT_JS_TS
   ```

2. **Verify your setup**
   ```bash
   node Chapter01-Basics/verifySetup.js
   ```

3. **Open in VS Code**
   ```bash
   code .
   ```

4. **Start learning!**
   - Open `Chapter01-Basics/javascript-keywords.md` to review JS keywords
   - Read through `Chapter01-Basics/identifier-rules.js` to understand naming rules
   - Check `Chapter01-Basics/vscode-shortcuts.md` to speed up your coding

---

## How to Use This Repository

### Running JavaScript Files

You can run any `.js` file using Node.js:

```bash
node Chapter01-Basics/identifier-rules.js
```

### Following Along

1. Read the `.md` reference files first to understand the concepts
2. Study the `.js` example files to see the concepts in action
3. Complete the `practice*.js` exercises on your own
4. Check your understanding by modifying the examples and observing the output
